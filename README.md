# BBM100 Descriptive Analytics: Business Report

This repository contains my business report for the BBM100 Descriptive Analytics module at Aston University.

## Project Overview
This project involved:
1. Analysing a real world housing/car market dataset using Excel.
2. Performing descriptive statistics, confidence intervals, ANOVA, and regression.
3. Building an asking price calculator to estimate prices based on key variables.
4. Communicating findings in an 8 page business report with visualisations and recommendations.

## Tools
1. Microsoft Excel (data cleaning, analysis, visualisation)
2. Descriptive statistics and inferential analysis (ANOVA, regression)
